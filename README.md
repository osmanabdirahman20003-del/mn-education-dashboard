# Minnesota K-12 Graduation Dashboard

## Overview
This project analyzes Minnesota K-12 graduation data by district using Python for data cleaning and Google Data Studio for visualization.

## Data Source
Minnesota Department of Education — public graduation data 2021-22

## Tools Used
- Python (pandas) for data cleaning
- Google Data Studio for dashboard visualization

## Live Dashboard
[View Dashboard Here](https://datastudio.google.com/reporting/8c3f5214-a33b-48ea-8df7-71a12662c75e)

## Files
- clean_data.py — Python script to clean and export the raw data
- graduates_clean.csv — Cleaned graduation counts by district
- indicators_clean.csv — Cleaned graduation indicators by district
